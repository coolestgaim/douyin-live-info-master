## 一、项目概述

**抖音直播控场助手**是一款基于 Electron 的抖音直播间信息采集与控制桌面工具，核心能力：

- **实时弹幕监听**：WebSocket 直连抖音弹幕服务器，解析 protobuf 协议，支持弹幕/礼物/点赞/进入/关注全类型消息
- **直播数据统计**：聚合展示多个直播间的观看、点赞、互动数据大屏
- **直播录制**：调用 ffmpeg 拉流录制直播，支持多种格式、多清晰度、分段录制
- **快捷控场**：嵌入式 webview 加载直播间页面，定位聊天输入框后一键发送快捷回复
- **历史记录**：SQLite 持久化弹幕历史，支持搜索、筛选、导出 CSV/JSON
- **授权管理**：HMAC 离线验签 + 在线验证 + COS 吊销黑名单

## 四、功能模块详解

### 4.1 📊 仪表盘 (DashboardView)

实时监控大屏，聚合所有已连接直播间数据。

| 功能 | 说明 |
|------|------|
| 统计卡片 | 弹幕/礼物/点赞/进入/关注 5 项总数聚合卡片 |
| 房间卡片 | 每个直播间独立卡片：头像（渐变）、昵称、直播状态、观看/点赞数、录制中标识 |
| 数据条形图 | 每房间 5 类数据横向条形对比（按最大值归一化） |
| 自动刷新 | 房间数据 2 秒轮询，API 统计 30 秒刷新 |
| 监控状态 | 顶栏显示监控中房间数、监控时长 |

### 4.2 📺 直播间 (LiveRoomsView)

直播间链接管理与信息获取。

| 功能 | 说明 |
|------|------|
| 批量输入 | 每行一个直播间链接，textarea 输入 |
| 历史记录 | 自动保存已查询链接，chip 形式点击回填，可单独删除 |
| 导入/导出 | .txt 文件导入链接、导出当前列表 |
| 信息表格 | 序号/主播/标题/点赞/观看/直播状态/弹幕连接状态 |
| 连接控制 | 单房间连接/断开、全部连接/全部断开 |
| 删除选中 | 从列表移除选中房间 |
| 错误处理 | 获取失败显示「失败」标记，不影响其他房间 |

### 4.3 💬 弹幕面板 (DanmuView)

实时弹幕监听与历史记录管理。

| 功能 | 说明 |
|------|------|
| 6 类 Tab | 全部/弹幕/礼物/点赞/进入/关注 分类实时展示 |
| 房间筛选 | 多房间连接时按房间 chip 筛选 |
| 弹幕浮窗 | 独立无边框半透明窗口，实时滚动显示，支持多房间 |
| 清空按钮 | 清空当前筛选条件下的消息 |
| 历史记录 | SQLite 持久化，按房间卡片展示（双击打开） |
| 历史检索 | 按类型/关键词/用户名过滤 |
| 数据导出 | 导出 CSV（带 BOM 防乱码）/ JSON |

### 4.4 ⏺️ 录制管理 (RecordingView)

直播流录制与文件管理。

| 功能 | 说明 |
|------|------|
| ffmpeg 管理 | 自动检测；缺失时弹窗引导下载（多源镜像） |
| 可录制列表 | 展示未在录制且非错误状态的直播间 |
| 单房间录制 | 一键开始，自动解析清晰度流地址 |
| 全部停止/单停止 | 灵活控制录制任务 |
| 实时状态 | 每个任务：时长、文件大小、状态（录制中/异常） |
| 输出格式 | MP3/MP4/WAV/FLV |
| 历史记录 | 停止后自动保存：昵称/时长/大小/时间戳 |
| 文件操作 | 打开文件所在位置、删除（带确认弹窗，同步删文件） |
| 重复录制 | 同房间可多次录制不覆盖，停止后可重新录制 |

### 4.5 📝 快捷回复 (QuickReplyView)

嵌入式 webview 控场，抖音直播页内一键快捷发送。

| 功能 | 说明 |

## 五、主进程架构

### 5.1 启动流程 (main.ts)

```
app.whenReady()
  ├── registerIpcHandlers()    # 注册全部 IPC 通道
  └── createWindow()           # 创建 1100x680 无边框窗口
        ├── preload.js         # contextBridge 注入 electronAPI
        ├── dev: loadURL(5173) # 有 dist/ 时优先加载本地文件
        └── close 事件 → cleanup() → app.exit(0)
```

关键点：
- `frame: false` 无边框窗口 + 自定义标题栏
- `webSecurity: false`（弹幕/接口请求需要）
- `webviewTag: true`（快捷回复 webview 需要）
- 生产环境优先加载 `dist/index.html`，否则走 Vite dev server

### 5.2 IPC 调度中心 (ipc-handlers.ts)

所有主进程能力统一在此注册，通过 `ipcMain.handle()` 提供异步通道。

### 5.3 核心服务说明

| 服务 | 职责 |
|------|------|
| `DouyinLiveService` | 抖音网页接口封装：解析房间 URL、获取直播间信息、刷新统计、管理 Cookie |
| `DanmuService` | 弹幕 WebSocket 长连接，收到二进制消息 → protobuf 解码 → 回调上抛 |
| `RecordingManager` | 多房间录制任务表管理（Map），异常自动标记 |
| `StreamRecorder` | 单路 ffmpeg 子进程封装（spawn），按 segment 分段 |
| `floating-danmu` | 独立 BrowserWindow 弹幕浮窗（透明、可筛选、置顶） |
| `license` / `license-online` | 离线 HMAC 验签 + 在线验证 + 心跳保活 + 机器码 |
| `database` | sql.js 封装：消息表、房间表、CRUD、导出 |

## 九、卡密授权系统

```
生成端 (keygen/)
  卡密生成器.html → HMAC-SHA256(uid + 过期天数) → base64url 编码
  admin.html → 生成记录 / 吊销（哈希入库）/ 导出 JSON

客户端 (electron/)
  license:verify → 本地 HMAC 验签（离线可用）
                → license-online 在线验证 + 机器码绑定
                → COS 吊销黑名单校验（license.ts）
  心跳保活 → 服务端记录在线状态
  下播下线 → deactivate 释放授权
```

## 十一、开发指南

### 启动开发环境

```bash
npm run electron:dev   # 启动 Vite (5173) + Electron
```

> 注意：若 `dist/` 存在，Electron 会优先加载打包文件而非 dev server。
> 开发时删除 `dist/` 或设置 `VITE_DEV_URL` 环境变量。

### 修改后验证

```bash
npm run build  # 必须通过（vue-tsc 严格类型检查）
```

### 注意事项

1. **webview 持久化**：视图必须常驻 DOM（v-show），不可 keep-alive 销毁
2. **窗口关闭**：`window-all-closed` 在有隐藏窗口时不触发，统一用 `app.exit(0)`
3. **清除登录**：`session.fromPartition().clearStorageData()` + webview.reload()×2
4. **Vue3 数组响应式**：v-for 直接 v-model 数组项会失效，用 `:value` + `@input` + 索引赋值
