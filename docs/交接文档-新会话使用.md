## 一、项目概述

抖音直播间信息采集与控场桌面工具，核心能力：

| 能力 | 说明 |
|------|------|
| 实时弹幕监听 | WebSocket 直连抖音弹幕服务器，protobuf 解码，6 类消息 |
| 直播数据统计 | 多直播间聚合大屏（弹幕/礼物/点赞/进入/关注） |
| 直播录制 | ffmpeg 拉流，多格式、多清晰度、分段录制 |
| 快捷控场 | 嵌入式 webview 加载直播间，定位输入框后一键发送 |
| 历史记录 | SQLite 持久化，搜索/筛选/导出 CSV/JSON |
| 卡密授权 | HMAC 离线验签 + 在线验证 + COS 吊销黑名单 |

**技术栈**：Electron 33.4 / Vue 3.5 / Pinia 2.2 / Naive UI 2.40 / Vite 6.4 / TypeScript 5 / sql.js / axios / ws / electron-builder 25

## 四、功能模块详解（8 视图）

### 1. 📊 仪表盘 DashboardView.vue
- 5 项聚合统计卡片（弹幕/礼物/点赞/进入/关注），渐变光效
- 每房间独立卡片：渐变色头像、昵称、直播状态、观看/点赞数、录制中标记
- 房间内 5 类数据条形图（按最大值归一化）
- 数据刷新：房间 2s 轮询，API 统计 30s
- 空态：无监控房间时的引导提示

### 2. 📺 直播间 LiveRoomsView.vue
- 批量链接输入（textarea 每行一个）
- 历史链接 chips（localStorage `douyin-room-history-v1`，最多 20 条，可单删）
- 导入 .txt / 导出链接
- n-data-table：序号/主播/标题/点赞/观看/直播状态/弹幕连接
- 单房间连接/断开、全部连接/全部断开、删除选中
- 行选中高亮（enterRoomId 比较 + style object，须包 computed）

### 3. 💬 弹幕 DanmuView.vue
- 6 Tab：全部/弹幕/礼物/点赞/进入/关注
- 多房间筛选 chips（filterRoomId）
- 弹幕浮窗（独立窗口：透明度滑块、类型Tab、房间筛选、自动滚动）
- 历史 Tab：房间卡片列表（双击打开详情）
- 历史检索：类型 radio + 关键词 + 用户名
- 导出 CSV（BOM 防乱码）/ JSON
- 浮窗关闭状态同步（onFloatingClosed 回调）

### 4. ⏺️ 录制 RecordingView.vue
- ffmpeg 检测 → 缺失弹窗引导下载（多源镜像，进度条）
- 可录制房间列表（排除错误/未开播/已录制中）
- 录制任务卡：时长/大小/状态（录制中/异常退出），实时刷新
- 操作：停止、新开录制（▶）、打开文件夹、删除（确认弹窗）
- 历史录制（localStorage `recording_history_v1`，最多 50 条）
- 清晰度选择：录制页显示清晰度下拉（仅当 >1 个选项时）
- 分段录制：设置页开关 + 时长

### 5. 📝 快捷回复 QuickReplyView.vue（手机卡片版 ⚠️）
> 当前版本是「手机卡片布局」（5831530 重构），**不是** douyin-live-simple 的简单版！
- 375px 手机竖屏卡片，每实例一卡，横向滚动
- 实例管理：+ 添加实例（ID 递增命名）、× 删除
- 每分组有「▶ 发送」「📝 编辑」双 Tab 切换
- 分组：新增/删除/折叠/重命名/加短语
- 按分组导出（JSON 单文件）
- 全局导入（importTargetId 机制，导入到当前实例）
- 精简模式：insertCSS/removeInsertedCSS 隐藏礼物/视频等，只留弹幕+输入框
- 发送机制：定位输入框 → 填字 → 聚焦 → 回车（不依赖发送按钮）
- 三连按钮（随机间隔 500-2500ms）
- webview：`persist:qr_<id>` 独立分区，静音，隐藏干扰元素

### 6. ⚙️ 设置 SettingsView.vue
- 输出格式：MP3/MP4/WAV/FLV
- 保存路径：自定义 + 浏览
- 分段录制开关 + 时长
- 授权管理：查看授权、清除卡密
- ⚠️ DashScope API Key 输入已删除（识图功能已删）

### 7. 🔑 卡密 LicenseView.vue

## 七、卡密授权系统

```
生成端 keygen/卡密生成器.html
  → HMAC-SHA256(2B过期天数 + 用户ID) → base64url → ~50字符
  → admin.html 管理：生成记录/吊销（哈希入库）/导出 JSON

客户端 electron/services/license.ts
  → 本地 HMAC 验签（离线可用，timingSafeEqual 防计时攻击）
  → license-online.ts：在线验证 + 心跳 + 机器码绑定
  → COS 吊销黑名单校验
启动流程：App.vue onMounted → licenseCheck() → 有效进入 / 无效显示 LicenseView
```

## 十、已知陷阱（必读！）

1. **dist/ 陷阱**：`dist/` 存在时 Electron 加载旧生产构建，源码改动无效。开发前必删。
2. **webview 持久化**：视图必须 v-show 常驻 DOM（App.vue），不可用 router-view/keep-alive 销毁重建，否则 webview 刷新丢登录。
3. **Pinia localStorage**：加载时必须用 `{...defaultInstance(), ...data}` 补齐字段，缺失字段导致模板 TypeError → 全页空白无报错。
4. **禁止 watch(store, {deep:true}) 持久化**：初始化触发无限循环 → 空白。用 mutation 后手动 persist()。
5. **n-data-table rowProps**：行选中须 `computed` + `enterRoomId` 比较 + style object。
6. **窗口关闭**：`window-all-closed` 有隐藏窗口时不触发，统一 `cleanup().finally(app.exit(0))`。
7. **清除登录**：`session.fromPartition().clearStorageData()` + webview.reload() ×2（间隔500ms）。
8. **Vue3 数组响应式**：v-for 中 v-model 数组项失效，用 `:value` + `@input` + 索引赋值。
9. **useDialog 需 n-dialog-provider**：否则整个组件静默崩溃空白。
10. **ffmpeg 路径**：查找链含 `process.resourcesPath/ffmpeg.exe`（打包后位置）。
11. **QuickReplyView 极其敏感**：改模板易空白，只改 store 优先。
12. **getCurrentWindow() 不存在**：Electron 33 浮窗用 IPC 通信，禁 remote 模块。
